# CryptoWorld – Cryptocurrency Website

A simple and beginner-friendly cryptocurrency website built using **HTML5**. CryptoWorld introduces users to popular cryptocurrencies, blockchain technology, digital payments, and online security.

## 🚀 Project Overview

CryptoWorld is a basic cryptocurrency information website designed to help users explore digital currencies such as Bitcoin, Ethereum, and Solana.

## ✨ Features

- **Home Section:** Welcome message and introduction to cryptocurrency.
- **About Section:** Learn about cryptocurrency and Bitcoin.
- **Popular Coins:** View Bitcoin, Ethereum, and Solana with their logos and symbols.
- **Crypto Features:** Information about digital payments, blockchain, and security.
- **Latest Crypto News:** Explore cryptocurrency-related information.
- **Contact Section:** Email information and social media links.
- **Navigation Menu:** Easily navigate between different sections.
- **Responsive Viewport:** Includes a viewport setting for mobile devices.

## 🛠️ Technologies Used

- HTML5
- HTML Tables
- Hyperlinks and Anchor Links
- Images
- Semantic HTML Elements
